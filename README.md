## Decision log (thresholds and reasons)
- Outliers: robust z = 0.6745*(x - median)/MAD within each crop+market series; flag |z| > 3.5 (Iglewicz & Hoaglin, 1993).
- Typo vs spike: ratio to median > 5 or < 0.2 -> data-entry error (set to missing); otherwise keep and flag.
- Prices: time interpolation, max gap 5 days. Arrivals: crop+market median (skewed variable).
- Dates parsed with explicit formats only (%Y-%m-%d, %d/%m/%Y, %d-%b-%Y); unknown formats fail loudly.
- Raw data is never modified; every imputed or flagged value has an audit column.
